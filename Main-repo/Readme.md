# CTK Vlogs 🎥🌍  
Dockerized & Kubernetes-Deployed Website on AWS EC2

CTK Vlogs is a static vlog website built using **HTML, CSS, and JavaScript**, hosted using **Nginx**, containerized with **Docker**, and deployed on **Kubernetes** running on an **AWS EC2 instance**.  
This project demonstrates a practical **DevOps deployment workflow** with scalability and rolling updates.

---

## 📌 Project Overview

- Static website for vlog content
- Served via Nginx
- Docker containerization
- Kubernetes Deployment & Service
- Hosted on AWS EC2
- Scalable using Kubernetes replicas

---

## 🧰 Technology Stack

| Layer | Technology |
|-----|-----------|
| Frontend | HTML, CSS, JavaScript |
| Web Server | Nginx |
| Containerization | Docker |
| Orchestration | Kubernetes |
| Cloud | AWS EC2 |
| OS | Ubuntu Linux |
